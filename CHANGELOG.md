# Changelog

## 1.0.0 - 2026-03-16

- Added mouse recording, playback, repeat count, loop mode, and playback speed control.
- Added optional keyboard recording and keyboard-event playback.
- Added import and export for recorded macros using the `.sreapeat.json` format.
- Added customizable global shortcuts with inline settings.
- Added warning and error logging under `%LocalAppData%\sreapeat\logs`.
- Added GitHub Actions for CI and automated tagged releases.
