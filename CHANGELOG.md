# Changelog

## 1.1.0 - 2026-04-21

- Add lock button on the record icon (toggle with F9) to prevent accidental macro overwrites.
- Add "All moves" option in settings to record every mouse movement instead of merging consecutive positions.
- Fix recording shortcut no longer fires when extra modifier keys are held alongside the configured key.
- Fix application log now includes exception message and stack trace for easier diagnosis.
- Fix playback timing no longer crashes on extremely large scaled delays.

## 1.0.0 - 2026-03-16

- First public release.
- Records and replays mouse actions, with optional keyboard capture.
- Includes repeat, loop, speed control, macro import/export, configurable shortcuts, and automated GitHub releases.
